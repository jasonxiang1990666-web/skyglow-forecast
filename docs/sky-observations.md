# 上海霞况历史观测校准

`forecast` 云函数从 `skyObservations` 集合读取人工复核的霞况结果，用于校准模型估算概率。集合权限建议设置为“仅管理员可读写”，小程序端不直接访问。

## 记录格式

```json
{
  "city": "上海",
  "type": "晚霞",
  "score": 78,
  "observedScore": 4,
  "targetAt": 1785326400000,
  "observedAt": 1785328200000,
  "source": "manual",
  "note": "西侧天空出现明显橙红色霞光"
}
```

- `city`：目前首阶段填写 `上海`。
- `type`：`朝霞`、`晚霞` 或 `火烧云`。
- `score`：当次预报产生的 0–100 霞况评分。
- `observedScore`：人工复核结果，推荐使用 0–4 分；3–4 分视为“值得观赏”。也支持直接填写 0–100。
- `targetAt`：预报目标观赏时段的 Unix 毫秒时间戳。
- `observedAt`：实际观察时间的 Unix 毫秒时间戳。
- `source`：如 `manual`、`photo-review`，仅用于追溯。

## 校准规则

- 总样本数达到 30 条后，上海 profile 才会标记为 `calibrated`。
- 评分被划分为 5 个区间（0–19、20–39、40–59、60–79、80–100）；当前区间至少有 5 条样本时，才会替换模型估算概率。
- 使用 Beta 平滑避免小样本直接产生 0% 或 100%。
- 样本不足时接口仍返回模型估算概率，并附带 `probabilityStatus: "pending"` 和 `probabilityLabel: "模型估算概率（待校准）"`。

建议先积累覆盖不同季节、不同天气类型的上海样本，再把结果用于正式概率展示。
